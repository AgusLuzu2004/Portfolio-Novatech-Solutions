# Dashboard Power BI

## Objetivo

Construir dashboards interactivos para el análisis comercial de NovaTech Solutions.

## Fuente de datos

- MySQL

## Modelo

- Esquema en estrella

## Medidas DAX

- Facturación
- Ticket promedio
- Clientes
- Productos vendidos

## Dashboard Ejecutivo

Incluye:

- KPIs
- Evolución mensual
- Ventas por categoría
- Top productos
- Ventas por provincia
- Medios de pago
- Canal de venta

Todos los gráficos son interactivos mediante segmentadores.

## Dashboard Comercial

Incluye:

- Ranking de vendedores
- Facturación por sucursal
- Top clientes
- Evolución interanual
- Participación por categoría
- Ventas por marca

### Funcionalidades (Comercial)

- Segmentadores sincronizados
- Drill-through
- Tooltips personalizados
- Formato condicional

## Dashboard Geográfico

Incluye:

- Mapa por provincia
- Ranking de provincias
- Evolución mensual
- Heatmap de ventas
- Indicadores YTD
- Crecimiento interanual

### Funcionalidades (Geográfico)

- Medidas DAX
- Navegación entre páginas
- Segmentadores sincronizados
- Tema personalizado
