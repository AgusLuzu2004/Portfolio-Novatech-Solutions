# Manual de Usuario

## Introducción

NovaTech Solutions es una aplicación de escritorio desarrollada en JavaFX para la gestión comercial de una empresa.

Permite administrar clientes, productos, empleados y ventas, además de consultar reportes y exportar información.

---

## Inicio de sesión

Al iniciar la aplicación aparecerá la pantalla de Login.

Complete:

- Usuario
- Contraseña

Presione **Iniciar Sesión**.

Se abrirá el menú principal, con las mismas opciones para cualquier usuario (el rol no restringe el acceso a ninguna pantalla por el momento).

---

## Menú principal

Desde el menú principal podrá acceder a:

**Gestión**: Clientes, Productos, Empleados, Ventas

**Reportes**: Reportes, Exportaciones

**Administración**: Usuarios, Auditoría, Configuración, Backups, Preferencias

Todas las opciones están disponibles para cualquier usuario logueado.

---

## Gestión de Clientes

Funciones disponibles:

- Agregar cliente
- Editar cliente
- Eliminar cliente
- Buscar por nombre
- Filtrar por provincia

---

## Gestión de Productos

Funciones disponibles:

- Alta de productos
- Modificación
- Eliminación
- Control de stock
- Búsqueda
- Filtrado por categoría

---

## Gestión de Empleados

Permite:

- Registrar empleados
- Asignar sucursal
- Editar información
- Consultar empleados

---

## Gestión de Ventas

Esta pantalla sirve para **registrar una venta nueva** (no muestra un historial de ventas ya realizadas).

Pasos:

1. Seleccionar cliente.
2. Seleccionar empleado.
3. Agregar productos.
4. Indicar cantidad.
5. Aplicar descuento (si corresponde).
6. Confirmar venta.

El sistema actualizará automáticamente el stock.

---

## Reportes

El módulo de reportes permite visualizar:

- Facturación
- Productos más vendidos
- Ranking de empleados
- Ventas por categoría
- Ventas por provincia

Los gráficos pueden filtrarse por distintos criterios.

---

## Exportación

Las tablas pueden exportarse a:

- Excel (.xlsx)
- PDF (.pdf)

---

## Copias de seguridad

Desde el módulo Backup es posible:

- Crear una copia de seguridad.
- Restaurar una copia existente.

---

## Salir de la aplicación

Menú **Archivo → Salir**.

Actualmente no hay un botón de "Cerrar sesión" independiente: para volver a la pantalla de login hay que cerrar la aplicación y abrirla de nuevo.
