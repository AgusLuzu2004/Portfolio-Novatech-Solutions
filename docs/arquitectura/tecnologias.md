## Arquitectura

El proyecto utiliza una arquitectura en capas:

- JavaFX
- Controller
- Service
- DAO
- MySQL

Esta arquitectura permite separar la interfaz, la lógica de negocio y el acceso a datos, facilitando el mantenimiento y la escalabilidad.

---

## Calidad del Software

Se implementaron las siguientes prácticas:

- Arquitectura por capas.
- Programación orientada a objetos.
- Pruebas unitarias con JUnit 5.
- Uso de Mockito para pruebas.
- Logging con Logback.
- Manejo de excepciones.
- Documentación técnica.
- Control de versiones con Git.

El proyecto fue desarrollado como portfolio personal con fines educativos y profesionales.

Su objetivo es demostrar conocimientos en:

- Desarrollo Java Desktop.
- Bases de datos relacionales.
- SQL.
- Análisis de datos.
- Power BI.
- Python.
- Buenas prácticas de desarrollo.
