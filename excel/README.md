# Dashboard Ejecutivo - Excel

## Objetivo

Construir un dashboard interactivo que permita analizar las ventas de NovaTech Solutions.

## Indicadores

- Facturación total
- Ticket promedio
- Cantidad de ventas
- Clientes únicos
- Productos vendidos

## Visualizaciones

- Evolución mensual
- Ventas por categoría
- Top 10 productos
- Ventas por provincia
- Medios de pago
- Canal de venta

## Herramientas utilizadas

- Tablas
- Tablas dinámicas
- Segmentadores
- Gráficos dinámicos
