# 📊 NovaTech Solutions

> Sistema de Gestión Comercial y Análisis de Datos desarrollado como proyecto de portfolio.

NovaTech Solutions es un proyecto integral que simula el trabajo realizado para una empresa ficticia dedicada a la comercialización de productos tecnológicos en Argentina.

El objetivo es demostrar habilidades en desarrollo de software, bases de datos, análisis de datos y visualización de información mediante un proyecto completo que integra múltiples tecnologías.

## ⭐ Características principales

- ✅ Sistema de gestión comercial desarrollado en Java.
- ✅ Base de datos relacional en MySQL.
- ✅ Generación y procesamiento de datos con Python.
- ✅ Dashboard ejecutivo desarrollado en Power BI.
- ✅ Arquitectura por capas (Controller – Service – DAO).
- ✅ Gestión de clientes, productos, empleados y ventas.
- ✅ Reportes y estadísticas.
- ✅ Exportación de información.
- ✅ Testing con JUnit y Mockito.
- ✅ Documentación técnica completa.

## 🏗 Arquitectura

```text
JavaFX

↓

Controller

↓

Service

↓

DAO

↓

MySQL
```

Esta arquitectura permite separar la lógica de negocio, el acceso a datos y la interfaz gráfica, facilitando el mantenimiento y la escalabilidad del proyecto.

## 🚀 Instalación

```bash
git clone https://github.com/AgusLuzu2004/Portfolio-Novatech-Solutions

cd Portfolio-Novatech-Solutions
```

### Requisitos

- Java 21
- Maven
- MySQL 8
- Git

Luego:

1. Crear la base de datos.
2. Ejecutar los scripts SQL.
3. Configurar la conexión a MySQL.
4. Ejecutar el proyecto Java.
