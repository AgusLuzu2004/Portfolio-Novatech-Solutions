# 📊 NovaTech Solutions - Portfolio

## 📌 Descripción

Este repositorio forma parte de mi portafolio personal y simula el trabajo realizado para una empresa ficticia llamada **NovaTech Solutions**, dedicada a la comercialización de productos tecnológicos en Argentina.

El objetivo del proyecto es demostrar conocimientos en análisis de datos, programación y gestión de bases de datos mediante el desarrollo de distintas soluciones utilizando información consistente y realista.

---

## 🎯 Objetivos

- Analizar información comercial.
- Diseñar una base de datos relacional.
- Construir dashboards ejecutivos.
- Automatizar procesos de limpieza de datos.
- Desarrollar un sistema de gestión de ventas.

---

## 📂 Módulos

### 📈 Excel

Dashboard interactivo con indicadores de negocio, tablas dinámicas y gráficos.

### 🗄 SQL

Modelo relacional de la empresa y consultas para responder preguntas de negocio.

### 📊 Power BI

Dashboard ejecutivo con indicadores, filtros e información comercial.

### 🐍 Python

Limpieza, transformación y preparación de datos utilizando Pandas.

### ☕ Java

Sistema de gestión para administrar clientes, productos y ventas.

---

## 📚 Dataset

Toda la información utilizada pertenece a una empresa ficticia creada exclusivamente con fines educativos.

El conjunto de datos incluye:

- Clientes
- Productos
- Ventas
- Empleados
- Sucursales
