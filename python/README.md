# Generador de Datos

Este módulo genera automáticamente el conjunto de datos utilizado por el proyecto NovaTech Solutions.

## Funcionalidades

- Generación de categorías
- Generación de sucursales
- Generación de productos
- Generación de clientes
- Generación de empleados
- Exportación automática a CSV

## Tecnologías

- Python
- Pandas
- Faker
